# Metal Group — comunicação corporativa e industrial

## Resumo

Conjunto contínuo de entregas para posicionamento e comunicação de uma empresa industrial, cobrindo identidade, planejamento editorial, newsletter, redes sociais e apresentação institucional.

## Entregas selecionadas

- Manual de marca.
- Calendário editorial para seis meses.
- Newsletter editorial com oito páginas.
- Carrossel institucional para social media.
- Apresentação corporativa de 65 slides.

## Competências demonstradas

- Adaptação de linguagem para um mercado B2B técnico.
- Planejamento de conteúdo de longo prazo.
- Consistência visual entre materiais institucionais e digitais.
- Organização de grandes volumes de informação em peças claras.
