# Portfólio de projetos recentes

Esta pasta reúne os trabalhos com melhor evidência visual, estratégica e técnica encontrados em `Documentos`. A organização preserva o padrão numérico já usado no acervo original, mas separa cada área por tipo de entrega e cada projeto por case, evidências e arquivos técnicos.

## Posicionamento profissional

**Sistemas de aquisição e operação para negócios de serviços:** landing pages, identidade visual, conteúdo, automações com IA e aplicações sob medida.

Essa formulação representa melhor o conjunto real do trabalho do que se apresentar apenas como designer, social media ou especialista em n8n.

## Base da curadoria

O levantamento catalogou 33.346 arquivos, 3.513 pastas e aproximadamente 68,6 GB. Documentos, apresentações, PDFs, planilhas, imagens, vídeos e estruturas de código relevantes foram inspecionados. Dependências técnicas, caches e bibliotecas repetidas foram contabilizados, mas não tratados como trabalho autoral.

## Nota importante sobre as aplicações

O material comprova uma versão empacotada para desktop do NeuroNex. VortexOS e Brand DNA devem ser apresentados como produtos web/mobile ou protótipos funcionais, e não como aplicativos desktop concluídos. Essa distinção fortalece o portfólio porque mantém todas as afirmações verificáveis.

## Como usar esta pasta

- Para enviar a um cliente, compartilhe apenas o case e as evidências do projeto relevante.
- Para o Fiverr, use os textos de `5. FIVERR - PERFIL & OFERTAS` como base e adapte somente exemplos, prazo e preço.
- Antes de publicar qualquer código, faça uma última revisão de privacidade.
- Não envie o acervo original inteiro. Esta pasta já é a seleção pública.
