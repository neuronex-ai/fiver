# Supabase — integração futura

A integração com Supabase ficará nesta pasta quando o projeto cloud for criado.

Planejamento inicial:

- `client.ts` — cliente do navegador.
- `auth.ts` — helpers de autenticação.
- `queries.ts` — consultas compartilhadas.
- `types.ts` — tipos gerados a partir do schema.

Variáveis previstas (já documentadas em `.env.example`):

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

Nenhuma conexão ou dependência de Supabase foi adicionada nesta etapa.
